### 2. `promoBannerVariants` — the `tone` axis

`tone="inverted"` flips the palette to `bg-foreground text-surface` — the same deliberate
palette inversion documented on `Tooltip`'s content surface — for a banner that needs to read as
a strong marketing moment against arbitrary page background.

## Background image and the scrim

When `imageSrc` is given, `PromoBanner` renders it full-bleed behind the content via `<Image>`
(never a raw `<img>`), plus a `bg-overlay` scrim so the heading/description stay legible over
arbitrary photography regardless of `tone`.

## CTA: button vs. link

Pass `onCtaClick` for an in-page action, or `href` to render the CTA as a link — `PromoBanner`
doesn't add its own `asChild` prop; it forwards to the `Cta` slot's own `asChild` support
(`Button` already has it), the same pattern `ProductCard` uses for its CTA.
