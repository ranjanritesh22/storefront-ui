## Why the whole sentence is one i18n function, not a template

`ResultsSummary` never assembles the "Showing X–Y of Z" string itself — it calls
`t.resultsSummary.showing({ start, end, total })` and renders whatever comes back
(CLAUDE.md rule 12). A function, not a `{start}`-style string template, is what lets a locale
reorder the words around the numbers, not just swap them in:

```tsx
configureMessages({
  resultsSummary: {
    showing: ({ start, end, total }) => `${total} Ergebnisse, ${start}–${end} angezeigt`,
  },
});
```
