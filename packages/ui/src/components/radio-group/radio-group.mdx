## FormField integration

```tsx
<FormField label="Size" error={errors.size}>
  <RadioGroup>
    <Radio value="s" label="Small" />
    <Radio value="m" label="Medium" />
  </RadioGroup>
</FormField>
```

`FormField` clones `id`/`aria-invalid`/`aria-describedby`/`data-invalid` onto the `RadioGroup`
root (`role="radiogroup"`), not onto individual `Radio` items — that's how a screen reader
announces the group's error state without repeating it per option.
