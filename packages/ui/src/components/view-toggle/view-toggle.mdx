## Keyboard interaction

A hand-rolled `role="radiogroup"` of `role="radio"` buttons with roving tabindex — only the
selected button is a tab stop; arrow keys move focus **and** commit the selection, matching
native `<input type="radio">` group behavior:

- <kbd>→</kbd>/<kbd>↓</kbd> selects the next option (wraps).
- <kbd>←</kbd>/<kbd>↑</kbd> selects the previous option (wraps).
- <kbd>Home</kbd>/<kbd>End</kbd> jump straight to grid/list.
- Each button carries a real `aria-label` (`gridLabel`/`listLabel`, defaulting to "Grid view"/"List
  view" via `getMessages()`) since it renders icon-only.
