## Overriding this component

The same `Price`, styled three different ways — cheapest override layer first. Full model:
[docs/overriding.md](../../../../../docs/overriding.md).

### 1. Tokens — rebrand every price at once

`--ui-color-danger` (sale price) and `--ui-color-foreground-muted` (struck-through original)
respond to the same `:root` / `[data-theme]` / `[data-brand]` overrides as everything else.
