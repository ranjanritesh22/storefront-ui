## Indeterminate

<Canvas of={ProgressBarStories.Indeterminate} />

Uses a `progress-indeterminate` keyframe animation declared once in `styles/index.css`'s
`ui-components` layer — a value-driven `width` transition can't express "duration unknown", so
indeterminate mode slides a fixed-width bar across the track instead.
