## Accessibility

Radix opens the tooltip instantly on keyboard focus (no hover delay), and closes it on blur,
Escape, or scroll. Because of that, a tooltip must only ever *supplement* an already-accessible
control — an icon button needs its own `aria-label` regardless of whether a `Tooltip` is attached,
since screen reader users may never trigger the tooltip's hover/focus state in the same way.
