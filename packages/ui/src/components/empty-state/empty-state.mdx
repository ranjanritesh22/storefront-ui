## EmptyState vs. ErrorState

- **EmptyState** — the request succeeded; there's just nothing to show. Icon is always
  consumer-supplied since the right glyph depends on context.
- **ErrorState** — the request failed. Always means the same thing, so it renders its own default
  icon, title, description, and retry action — see [ErrorState](../error-state/error-state.mdx).
