`--ui-color-border`, `--ui-color-surface`, `--ui-color-danger`, `--ui-shadow-md` on `:root` or
scoped under `[data-theme]` / `[data-brand]`.

## Submenus

`DropdownMenuSub` / `DropdownMenuSubTrigger` / `DropdownMenuSubContent` nest a second-level menu
off any item — see "Move to collection" in the playground above. The submenu opens on hover or
`ArrowRight` and closes on `ArrowLeft`, matching native OS menu behavior.
